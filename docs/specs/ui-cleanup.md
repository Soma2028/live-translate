# 仕様: 通話画面のUI整理

> **状態: 実装済み**（ステータス行の統合、音量バーのアイコン、使用量の設定メニュー移動、Escヒントの出し分け）

## 背景

機能を追加するたびに画面上部へ情報が積み上がり、
現在は通話中に以下の4段が常時表示されている。

```
[00:00] [バー] [バー] [開始] [切る]              [⚙]
シグナリング中…
今月 4,456 / 2,000,000 文字
マイクの許可が必要です。Chrome または Edge で開いてください。
```

このアプリで最も長く見るのは字幕エリアであり、
1回の通話で1時間を超えることもある。
上部の常時表示を削り、字幕に面積を割きたい。

## 目標の形

```
[00:00]  🎤▬▬▬  👤▬▬▬   [開始] [切る]          [⚙]
──────────────────────────────────────────
                （字幕エリア）
──────────────────────────────────────────
[ 音声が届かないときはここに入力 ]
```

## 対象ファイル

`call.html`

---

## 1. ステータス行を1行に統合する（最優先）

現在の4段を、ヘッダーの1行に収める。

### 「シグナリング中…」

- 接続が確立したら消す
- 接続処理中と、エラー時のみ表示する

### 「マイクの許可が必要です。Chrome または Edge で開いてください。」

- マイクが許可済みのときは表示しない
- 実際に許可が得られていない、またはブラウザが非対応のときだけ出す
- 現在は許可済みでも出ているので、条件を見直すこと

### 「今月 4,456 / 2,000,000 文字」

- 常時表示をやめる
- 設定メニュー（歯車）の中に移す
- 上限に対して 1% 未満しか使っておらず、通話中に見る情報ではない

### 残すもの

- 経過時間
- 音量バー（自分・相手）
- 開始／停止、切る
- 設定（歯車）

エラーや警告は、発生したときだけヘッダー下に1行で出す。
消えたら元の高さに戻す。

---

## 2. 音量バーにラベルを付ける

現在バーが2本並んでいるだけで、どちらが自分でどちらが相手か分からない。

- 各バーの左に小さくアイコンを置く
  - 自分: マイクのアイコン
  - 相手: 人のアイコン
- アイコンは画像ファイルを使わず、インラインSVGか文字で表現する
  （依存を増やさない）
- バーが動いていない状態と、相手が未接続の状態を見分けられるようにする
  （未接続時はバー自体を薄くするなど）

---

## 3. 下部のヒント行

「Escキーで直前の字幕を取り消せます。」が常時表示されている。
一度読めば十分な情報なので、常に場所を取る必要はない。

以下のいずれかにする。

- 通話開始から数秒だけ表示して自動的に消す
- または入力欄にフォーカスがあるときだけ表示する

---

## 4. 字幕エリアを縦に最大化する

1〜3で削ったぶん、字幕エリアの高さを広げる。

- 上部ヘッダーと下部入力欄を除いた残り全部を字幕エリアにする
- 字幕が少ないときの案内文（「開始」を押して話すと…）は
  中央に置いたままでよい

---

## やらないこと

- 配色やフォントの変更
- 字幕の吹き出しデザインの変更
- 設定メニュー内の項目の並び替え

今回は「常時表示を減らして字幕に面積を渡す」ことだけに絞る。

---

## 確認方法

1. 通話が確立した状態で、上部が1行になっていること
2. マイク許可済みのときに「マイクの許可が必要です」が出ないこと
3. マイクを拒否した状態では、その警告が出ること
4. 音量バーが自分と相手で区別できること
5. 「今月○文字」が設定メニューから確認できること
6. 字幕エリアが以前より明らかに広いこと
