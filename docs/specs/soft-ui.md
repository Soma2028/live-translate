# 仕様: UIをやわらかい印象にする

> **状態: 実装後に取り消し**（`4ac6ed5`〜`d25d557` で実装 → `af7f8a0` で取り消し）

## 目的

現在のUIは機能優先で作ってきたため、やや硬く事務的な印象がある。
親しい友人同士で毎日使うアプリなので、もう少しやわらかく、
親しみのある見た目にしたい。

## 大前提: 字幕の可読性は絶対に落とさない

このアプリは1回の通話で1時間以上、字幕を読み続ける。
装飾のために可読性を犠牲にすると、アプリとして成立しなくなる。

そのため、**変えていい範囲と変えてはいけない範囲を明確に分ける**。

### 変えてはいけないもの

- 字幕本文（原文・訳文）のフォントファミリー
  （現行の Noto Sans JP / Noto Sans KR のまま）
- 字幕本文の文字色と背景色のコントラスト比
- 字幕本文の文字サイズ
- 字幕本文の行間

装飾のために文字を薄くしたり、丸っこいフォントに変えたりしない。

### 変えていいもの

以下は可読性に影響しないため、自由に調整してよい。

- ボタンの形状・押下時の挙動
- 吹き出しの角丸・影
- ヘッダーと設定メニューの配色
- 空の状態（字幕がまだ無いとき）の案内表示
- 接続・切断時のアニメーション
- 入力欄の見た目

---

## 具体的な変更

### 1. 角丸をやわらかく

- ボタンの `border-radius` を現在より大きくする
- 吹き出しの角丸も大きくする
- ただし完全な円形（pill 型）にはしない。丸すぎると幼く見えすぎる

### 2. 影をやわらかく

- 吹き出しの影を、輪郭のはっきりした影ではなく
  広がりのあるぼかした影にする
- 濃さは控えめに。字幕の縁が曖昧にならない程度

### 3. ボタンの押下感

- ホバー時にわずかに浮く、押下時にわずかに沈む
- `transition` は 150ms 程度。もたつかない速さにする
- 過度なバウンドやスケール変化はしない

### 4. 配色のやわらかさ

- 背景色をわずかに暖かみのある方向へ寄せる
- アクセント色（`--ja` / `--ko`）は彩度を少し落とし、
  主張しすぎない色味にする
- ただし**字幕本文の文字色（`--ink`）は変えない**。
  背景とのコントラストを維持すること

### 5. 空の状態

現在は「「開始」を押して話すと、ここに字幕が出ます。」という
テキストだけが中央に置かれている。

- ここにやわらかいイラスト的な要素を足す
- 画像ファイルは使わず、インラインSVGか絵文字で表現する
  （依存を増やさないため）
- 文言もややくだけた調子にしてよい。i18n に韓国語も用意すること

### 6. 接続時のアニメーション

- 相手が参加したとき、吹き出しエリアや
  ヘッダーの状態表示がふわりと変化する
- 派手な動きは不要。200〜300ms の穏やかなフェードで十分

---

## やらないこと

- キャラクターやマスコットの追加
- 字幕の吹き出しに顔や装飾をつける
- 背景に柄やグラデーションを敷く
- 効果音の追加（現在の参加音・退出音のみ維持）

---

## 確認方法

1. 字幕本文のフォント・サイズ・色が変わっていないこと
2. 1時間読み続けても疲れない状態が保たれていること
   （コントラストが下がっていないこと）
3. ボタンや吹き出しの印象がやわらかくなっていること
4. 空の状態が寂しくなくなっていること
5. 韓国語UIでも文言が用意されていること
6. ヘッダーが1行のまま崩れていないこと
