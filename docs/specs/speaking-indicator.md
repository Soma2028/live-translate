# 仕様: 発話中インジケーター

> **状態: 実装後に削除**（`036a810` で実装 → `c3334dc` で削除。ヘッダーの音量バーは維持）

## 背景

通話中、「いま自分が話しているのか、相手が話しているのか」が
一目で分かりにくい。

現状で話者を区別できる要素は3つある。

- 吹き出しの左右（自分が右、相手が左）
- アイコン（JA / KO）
- ヘッダーの音量バー

ただしこれらは、字幕が出たあとに初めて分かるもの、
あるいは画面上部にあって視線を動かす必要があるものばかりで、
**いま誰が話している最中なのか**は分からない。

字幕を読んでいる間、視線は画面の中央から下にある。
そこで判断できるようにしたい。

## 対象ファイル

`call.html`

## 実装

### 表示位置

字幕エリアの**最下部**に表示する。

次の字幕が追加される位置なので、視線移動がほとんど発生しない。
「次にここへ何かが出る」という予告としても機能する。

### 表示内容

- 自分が話しているとき: 字幕エリア最下部の**右寄せ**
- 相手が話しているとき: 字幕エリア最下部の**左寄せ**
- 両方が同時に話しているときは、左右どちらも表示する

表示するものは、吹き出しと同じ形の小さなプレースホルダとし、
中に「…」がアニメーションするものを入れる。
（メッセージアプリのタイピングインジケーターと同じ考え方）

既存の話者アイコン（JA / KO）も一緒に表示すると、
どちらが話しているか二重に分かるのでよい。

### 表示・非表示の条件

判定にはすでに取得している音量データを使う。

- 自分: `AudioContext` / `AnalyserNode` で取得している自分のマイク音量
- 相手: DataChannel で受信している `mic-level`

条件は以下。

- 音量が一定のしきい値を超えたら表示する
- 無音が **1秒** 続いたら消す
- しきい値は定数 `SPEAKING_THRESHOLD` として定義し、
  あとから調整できるようにする

相手から `mic-level` が3秒以上届いていない場合（未接続・STT未開始など）は、
相手側のインジケーターを一切表示しない。

### スクロールとの関係

- インジケーターは常に字幕リストの末尾に位置する
- 新しい字幕が追加されたとき、インジケーターより上に挿入する
  （インジケーターが常に最下部に残るようにする）
- 自動スクロールの対象に含め、インジケーターが画面外に隠れないようにする

---

## やらないこと

- 音量バー（ヘッダー）の削除や移動
- 吹き出しの配色・デザインの変更
- 「入力中」のようなテキスト入力の通知

---

## 確認方法

1. 自分が話すと、字幕エリア最下部の右側にインジケーターが出る
2. 話し終えて1秒ほどで消える
3. 相手が話すと、左側に出る
4. 相手が接続していない、または「開始」を押していない状態では
   左側のインジケーターが出ない
5. 新しい字幕が出ても、インジケーターが最下部に残っている
6. 字幕が増えてもインジケーターが画面外に隠れない
